Saving and moving progress

Your child's progress lives in your browser, not on our servers. Export a backup file in one click, restore it on another device, and know what clearing data erases.

Where progress is kept

There are no accounts on learnCoreSkills. When you add a child and they practise, the profile and the results are saved in your own browser, on the device you are using. We do not receive them and we do not keep a copy on a server. That is good for privacy, but it means the progress belongs to that browser on that device, and it does not follow your child to a tablet, a school computer or a different browser by itself.

Saving a copy: export

Open the Parent Area from the menu and make sure the right child is active. Press "Export this child's data". Your browser downloads a file named after the child. It contains the profile and the practice results, and it goes only where you choose to keep it, for example your downloads folder, a memory stick or your own cloud storage.

Make a habit of exporting now and then, especially after a good run of practice or before changing devices. It takes a few seconds.

Moving to another device: import

On the other device, open the Parent Area and press "Import a child's data". This works even if no child exists there yet. Choose the file you exported earlier. The profile and the results appear, and your child can carry on where they stopped.

If a profile with the same name already exists on that device, the site asks what you want to do. You can import the file as a new profile, replace the data of the existing profile, or cancel. Pick "new profile" if you are not sure, since it never overwrites anything.

If the file cannot be used, the site tells you, for example when it is not a genuine export or when it comes from a newer version of the site. In that case nothing is added.

What is lost when browser data is cleared

Clearing your browser's site data or cookies, using a cleaning tool, resetting the browser, or a school computer that wipes itself at logout will remove the children's profiles and all their progress. The same applies to the "Delete this child" button, which asks for confirmation first because it cannot be undone. Without an export, there is no way for us to bring it back, since we never had a copy.

A private or incognito window behaves the same way, and the data is gone as soon as the window closes. Switching to a different browser or a different browser profile on the same computer also starts you from a blank page.

A simple routine

Export once a month, or whenever your child has made visible progress. Keep the file somewhere you will find it. If you ever lose your data, import the latest file and you are back, only missing what happened since.
