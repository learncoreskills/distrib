A Terms of use page, and a home page that search engines can read

The site now has a Terms of use page next to Privacy, About and Contact, in English and French, linked from the footer on every screen. The plain-HTML copy of the home page, which crawlers read when they do not run scripts, also gained a short "About this site" paragraph and the same four footer links, so the trust pages are reachable from the very first page a crawler sees.

The blog index page now lists every post as a normal link in the page itself, instead of loading the list only after the page starts, so search engines see the posts too.

The home page's plain-HTML copy is now a full page of text, with a how-it-works section, a short list of common questions and a note on privacy and advertising. The site also loads faster on a first visit: the parent area, the practice screens and the documentation pages are now fetched only when someone opens them, instead of being downloaded with the very first screen.
