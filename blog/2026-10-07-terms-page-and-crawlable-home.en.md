# A Terms of use page, and a home page that search engines can read

The site now has a Terms of use page next to Privacy, About and Contact, in English and French,
linked from the footer on every screen. The plain-HTML copy of the home page, which crawlers read
when they do not run scripts, also gained a short "About this site" paragraph and the same four
footer links, so the trust pages are reachable from the very first page a crawler sees.

The blog index page now lists every post as a normal link in the page itself, instead of loading the
list only after the page starts, so search engines see the posts too.
