Quand quelque chose ne fonctionne pas

Progression non enregistrée, page qui ne s'affiche pas, message sur le stockage ? Des vérifications rapides pour les causes habituelles, dans l'ordre où les essayer.

La progression n'est pas enregistrée

Le site affiche le message « La progression pourrait ne pas être enregistrée sur cet appareil pour le moment » lorsqu'il ne parvient pas à utiliser son espace de stockage dans votre navigateur. Prenez-le au sérieux : les résultats de cette visite pourraient être perdus. Voici les causes les plus courantes.

  • Vous êtes dans une fenêtre privée ou de navigation incognito, qui oublie tout à sa fermeture.
  • Le navigateur bloque les données de site ou les témoins (cookies), ou il est réglé pour les effacer à chaque fermeture.
  • Un outil de confidentialité, une application de nettoyage ou un réglage de l'école ou du travail efface les données du navigateur.

Ouvrez le site dans une fenêtre normale, autorisez-le à conserver des données et réessayez. Si le profil de votre enfant a disparu, vérifiez que vous utilisez le même navigateur, sur le même appareil, qu'auparavant. Un autre navigateur, ou une autre session d'utilisateur sur l'ordinateur, a ses propres données. Si vous avez un fichier exporté, vous pouvez restaurer un profil depuis l'espace parent.

Une page ne s'affiche pas

Commencez par le plus simple. Vérifiez votre connexion internet, puis actualisez la page. Si une seule page échoue, retournez à la page d'accueil et naviguez à partir de là. Si vous avez ouvert un ancien signet ou un lien qu'on vous a transmis, essayez la page d'accueil, car une adresse peut avoir changé. Essayer un autre navigateur ou redémarrer l'appareil règle la plupart des autres cas. La documentation et les articles affichent un court message « temporairement indisponible » quand ils ne peuvent pas être récupérés ; patientez un instant et réessayez.

Le chargement est lent

Le site charge son contenu par internet : une connexion lente peut donc entraîner une courte attente, surtout la première fois que vous ouvrez quelque chose. Se rapprocher du routeur Wi-Fi, fermer les autres onglets et applications qui utilisent la connexion, et patienter quelques secondes avant d'appuyer de nouveau aident généralement.

L'utiliser hors ligne

Il n'existe pas de mode hors ligne. Le site a besoin d'une connexion internet pour s'ouvrir, et nous ne pouvons pas promettre qu'une séance continuera de fonctionner si la connexion est coupée. Si votre connexion est instable, ouvrez l'activité tant que vous êtes connecté et restez sur cet écran. Pour un voyage, la feuille de calcul mental à imprimer est une bonne solution de rechange : imprimez-la ou enregistrez-la en PDF à l'avance.

Toujours bloqué

Essayez un autre navigateur, vérifiez qu'il est à jour et réessayez. Si un problème reste inexpliqué, la page Contact indique comment nous écrire. Dites-nous l'appareil, le navigateur et ce que vous avez vu à l'écran. En attendant, si la progression de votre enfant compte pour vous, commencez par exporter un fichier de sauvegarde depuis l'espace parent.
